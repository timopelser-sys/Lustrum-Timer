# Lustrum Timer

Aftellen naar 21:35, 22:35, 23:35, 00:35 en 01:35 (26–27 november 2026). Zwart scherm met paarse LED-cijfers. Op 0 staat één minuut lang de tekst van dat uur in beeld.

- **Beamer (laptop):** `index.html`. Klik één keer om te starten, dan gaat het scherm naar volledig scherm.
- **Telefoon:** `bediening.html`. Hiermee stel je de teksten in en zet je een tekst op het scherm.
- **Testen:** `index.html?test` laat elke 2 minuten een moment afgaan.

De timer rekent steeds vanaf de klok van de laptop. Na het laden heeft hij geen internet meer nodig. De telefoon stuurt berichten via ntfy.sh. Valt het internet weg, dan blijft de timer gewoon lopen.

Sneltoetsen op de laptop: F (tekst nu tonen), S (stop), T/W (tekst onder de timer zetten of weghalen), +/- (klok ±1 s), H (hulp).
